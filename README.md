# Olist Business Intelligence

A Streamlit workspace for exploring Olist e-commerce data.

## Run locally

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Place source datasets in `data/`, reusable Python modules in `src/`, Streamlit pages in `pages/`, and project notes in `docs/`.
